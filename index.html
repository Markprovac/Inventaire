Modifier mon code PIN

Le stock et l'historique ne sont pas modifiés. Après une réinitialisation par l'administrateur, saisis ici le PIN temporaire puis choisis ton nouveau PIN personnel.

🔐 Administration — réinitialiser un PIN oublié
Réservé à l'administrateur. Le mot de passe administrateur n'est jamais enregistré dans le téléphone. Le nouveau PIN est temporaire et devra être remplacé par le technicien.

Synchronisation de mon stock

Chaque modification reste d'abord enregistrée sur le téléphone, puis elle est envoyée automatiquement vers ton stock Cloudflare. Les photos restent locales pour éviter d'activer R2 et tout risque de facturation.

Sauvegardes quotidiennes

Le Worker crée chaque nuit une copie de chaque stock dans D1 et conserve les 30 derniers jours.

Import / Export

Le CSV est pratique pour Excel. La sauvegarde JSON conserve aussi les photos et l'historique.

Importer

Colonnes CSV acceptées : code-barres, référence, désignation, type, marque, machine, emplacement, quantité, stock minimum, fournisseur, prix, notes.

Zone sensible
