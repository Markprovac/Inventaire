Compte technicien

Le numéro de dépôt identifie ton stock personnel. Le code PIN empêche un autre utilisateur de modifier ton inventaire en saisissant simplement ton numéro.
La sauvegarde en ligne n'est pas encore configurée sur ce téléphone.

Modifier mon code PIN

Le stock et l'historique ne sont pas modifiés. Après une réinitialisation par l'administrateur, saisis ici le PIN temporaire puis choisis ton nouveau PIN personnel.

Synchronisation de mon stock

Chaque modification reste d'abord enregistrée sur le téléphone, puis elle est envoyée automatiquement vers ton stock cloud. Les photos restent dans ton téléphone.

Sauvegardes quotidiennes

Chaque nuit une sauvegarde est effectuée dans le cloud et conserve les 30 derniers jours.

Supprimer mon compte cloud

Cette opération désactive ton compte pendant 30 jours. Ton stock dans le cloud reste restaurable par l'administrateur pendant ce délai, puis il est supprimé définitivement. Le stock présent sur ce téléphone n'est pas effacé.

Ce bouton ne sert pas à changer de téléphone : pour cela, reconnecte simplement le nouvel appareil avec le même numéro de dépôt et le même PIN.

Import / Export

Le CSV est pratique pour Excel. La sauvegarde JSON conserve aussi les photos et l'historique.

Importer

Colonnes CSV acceptées : code-barres, référence, désignation, type, marque, machine, emplacement, quantité, stock minimum, fournisseur, prix, notes.
